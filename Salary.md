# Employee Salary Management System 

## About the Project

The Employee Salary Management System is a beginner-friendly Python project built to practice Object-Oriented Programming (OOP).

It calculates employee salaries based on basic salary, bonus, and allowance. It also includes a `Manager` class that inherits from the `Employee` class and receives an additional manager bonus.

## Features

- Store employee names and basic salaries.
- Calculate salaries with optional bonuses and allowances.
- Create a Manager class using inheritance.
- Add an extra Rs. 5,000 manager bonus.
- Display employee details and department information.
- Demonstrate method overriding and `super()`.

## Concepts Practiced

- Classes and Objects
- Constructors (`__init__`)
- Instance Attributes
- Inheritance
- Method Overriding
- `super()`
- Default Parameters
- Return Statements
- String Formatting

## How to Run

1. Install Python 3 on your computer.
2. Clone this repository or download the project files.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python employee_salary.py
```

*Replace `employee_salary.py` with your actual Python filename if it differs.*

## Salary Calculation

**Employee:**

Basic salary + bonus + allowance

Rs. 30,000 + Rs. 3,000 + Rs. 2,000 = **Rs. 35,000**

**Manager:**

Basic salary + bonus + allowance + manager bonus

Rs. 50,000 + Rs. 5,000 + Rs. 2,000 + Rs. 5,000 = **Rs. 62,000**
